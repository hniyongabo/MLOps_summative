Data insights

Balanced classes. {{ data.total }} images in total. Each disease class has between {{ data.min_class }} and {{ data.max_class }} training images, so the model is not biased towards one class and accuracy is a fair measure. 25% of the original training data is held back as the retrain pool: new data for the retraining demo.

Colour tells part of the story. {{ data.greenest }} leaves are the greenest on average and {{ data.least_green }} the least green (mean share of green: {% for k, val in data.mean_green.items() %}{{ k }} {{ val }}{{ ', ' if not loop.last }}{% endfor %}). Disease turns leaf tissue brown/yellow, but the boxes overlap, so colour alone is not enough and the network also has to learn spot shapes and texture.

What the classes look like. Angular leaf spot gives brown, angular patches bounded by the leaf veins; bean rust gives many small reddish-brown pustules; healthy leaves are uniformly green. Photos were taken in the field with phones, so backgrounds, lighting and angles vary. That is why the model uses data augmentation and a pre-trained network.
